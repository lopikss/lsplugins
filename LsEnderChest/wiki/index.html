LsEnderChest

LsEnderChest is a modern Ender Chest replacement for Paper 1.21.x servers. It replaces the vanilla fixed-size Ender Chest with a permission-based expandable storage system, allowing servers to give players different storage sizes depending on rank, perks, or progression. It is designed to stay lightweight, easy to manage, and flexible enough for both simple and more advanced setups.

Overview

Vanilla Minecraft limits Ender Chests to a fixed size. LsEnderChest replaces that behavior with a custom system that lets you decide how many rows a player should have based on permissions.

This makes it ideal for survival servers, donor ranks, store perks, progression systems, and admin tools. A player can have anywhere from 1 to 6 rows, while staff can inspect other players’ storage when needed.

Because the plugin uses its own storage handling, it is not tied to the limitations of the vanilla Ender Chest system. That allows it to support larger inventories, staff access, and offline player viewing in a clean way.

LsEnderChest is designed to stay lightweight and simple for server owners while still supporting more advanced setups through SQLite and MySQL.

Features

  • Expandable storage – Players can have between 1 and 6 rows depending on their permissions.
  • Rank-based upgrades – Perfect for survival servers that use permissions or ranks to reward players with additional storage.
  • Staff inspection tools – Administrators can open and inspect another player's Ender Chest for moderation, support, or item recovery cases.
  • Offline player support – Staff can view the Ender Chests of players even when they are offline.
  • Flexible database storage – Supports both SQLite and MySQL for different server environments.
  • Lightweight architecture – Designed to run efficiently without adding unnecessary load to your server.
  • Vanilla replacement – Replaces the standard Ender Chest flow with the plugin system for better control and customization.
  • Offline-mode support – Can be used on both online-mode and offline-mode servers where supported by your setup.

Commands

LsEnderChest keeps commands intentionally small and easy to remember so players and staff can use it without needing to learn a complex command system.

/lsec

Opens your personal Ender Chest using the plugin’s custom storage system. The inventory size will automatically adjust depending on the highest row permission the player has been granted.

/lsec <player>

Opens the Ender Chest belonging to another player. This command is intended for administrators and moderators who need to inspect, verify, or manage a player's stored items. 

/lsec
/lsec <player>

Permissions

Permissions control both access and storage size. This makes the plugin very easy to integrate with rank systems, store packages, or progression-based permission setups using plugins such as LuckPerms.

Access Permissions

  • enderchest.use — allows a player to open their own chest
  • enderchest.admin — allows opening other players’ chests
  • enderchest.bypass — bypasses restrictions where applicable

Row Permissions

  • enderchest.rows.1 — 1 row
  • enderchest.rows.2 — 2 rows
  • enderchest.rows.3 — 3 rows
  • enderchest.rows.4 — 4 rows
  • enderchest.rows.5 — 5 rows
  • enderchest.rows.6 — 6 rows

In practice, you would usually assign these row permissions to ranks. For example, default players may get 1 or 2 rows, while VIP or higher tiers receive larger Ender Chests.

Storage System

LsEnderChest stores chest contents outside of the vanilla Ender Chest system. This makes it possible to support expandable sizes, offline access, and more flexible data handling.

SQLite

SQLite is the easiest option and is usually the best default for single-server setups. It does not require any external database software and works well for most small and medium servers.

MySQL

MySQL is better suited for larger environments or networks that prefer dedicated database infrastructure. It is also a stronger option when you want your storage managed outside the local server files.

Why database-backed storage matters

  • Supports non-vanilla inventory sizes
  • Makes offline player data easier to manage
  • Keeps storage separate from Mojang’s default Ender Chest handling
  • Allows staff tools to access saved chest data more reliably

Practical Use Cases

LsEnderChest works especially well on servers where storage is part of progression, monetization, or moderation.

  • Give default players a small Ender Chest and higher ranks more space.
  • Offer extra rows as a store perk without creating separate storage plugins.
  • Allow staff to inspect chests during support tickets or moderation cases.
  • Review offline player storage when handling reports, suspicious activity, or recovery requests.

Compatibility

  • Server software: Paper
  • Minecraft version: 1.21.x
  • Java version: Java 21

The plugin is intended for modern Paper servers and is built around current API expectations for the 1.21.x version range.

Installation

Installing LsEnderChest is straightforward and only takes a few steps. 

1. Download the plugin jar
2. Place it in your server's plugins folder
3. Start or restart the server
4. Edit config.yml if needed
5. Assign row permissions to your ranks
6. Test /lsec in-game to confirm everything works
