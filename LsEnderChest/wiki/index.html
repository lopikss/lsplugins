LsEnderChest

LsEnderChest is a modern Ender Chest replacement for Paper 1.21.x servers. It turns the vanilla Ender Chest into a permission-based expandable storage system with support for rank upgrades, offline players, and database-backed persistence.

Overview Features Commands Permissions Storage Compatibility Installation

Overview

Vanilla Minecraft limits Ender Chests to a fixed size. LsEnderChest replaces that behavior with a custom system that lets you decide how many rows a player should have based on permissions.

This makes it ideal for survival servers, donor ranks, store perks, progression systems, and admin tools. A player can have anywhere from 1 to 6 rows, while staff can inspect other players’ storage when needed.

LsEnderChest is designed to stay lightweight and simple for server owners while still supporting more advanced setups through SQLite and MySQL.

Features

  • Expandable Ender Chest sizes from 1 to 6 rows
  • Permission-based progression for ranks and upgrades
  • /lsec to open your own Ender Chest
  • /lsec <player> for staff access to player storage
  • SQLite support for easy setup
  • MySQL support for larger or more advanced servers
  • Support for online-mode and offline-mode environments
  • Offline player chest viewing
  • Admin bypass support

Commands

LsEnderChest keeps commands intentionally small and easy to remember.

/lsec

Opens your own Ender Chest using the custom storage system. The size of the inventory depends on the highest row permission the player has.

/lsec <player>

Opens another player’s Ender Chest. This is meant for administrators or staff members who need to inspect inventories, help players, or moderate storage abuse. 

/lsec
/lsec <player>

Permissions

Permissions control both access and storage size. This lets you easily connect the plugin to rank systems through LuckPerms or any other permission manager.

Access Permissions

  • enderchest.use — allows a player to open their own chest
  • enderchest.admin — allows opening other players’ chests
  • enderchest.bypass — bypasses restrictions where applicable

Row Permissions

  • enderchest.rows.1
  • enderchest.rows.2
  • enderchest.rows.3
  • enderchest.rows.4
  • enderchest.rows.5
  • enderchest.rows.6

The plugin should use the highest matching row permission for the player, so you can safely give higher ranks larger storage without needing separate command aliases or multiple plugin instances.

Storage System

LsEnderChest stores chest contents outside of the vanilla Ender Chest system. This makes it possible to support expandable sizes, offline access, and more flexible data handling.

SQLite

SQLite is the easiest option and is usually the best default for single-server setups. It does not require any external database software and works well for most small and medium servers.

MySQL

MySQL is better suited for larger environments or networks that prefer dedicated database infrastructure. It is also the stronger option when you want more control over data storage outside the local plugin folder.

Why database-backed storage matters

  • Supports non-vanilla inventory sizes
  • Makes offline player data easier to manage
  • Keeps storage separate from Mojang’s default Ender Chest handling
  • Helps staff open saved data directly through the plugin

How the plugin is useful on real servers

LsEnderChest is especially useful when you want storage to be part of progression or monetization without making the system confusing for players.

  • Give default players 1 or 2 rows
  • Give higher ranks more rows as a perk
  • Let staff inspect player storage during support cases
  • Use offline access to review inventories even when the player is not online

Compatibility

  • Server software: Paper
  • Minecraft version: 1.21.x
  • Java version: Java 21

Installation

Installing LsEnderChest is straightforward. 

1. Download the plugin jar
2. Place it in your server's plugins folder
3. Start or restart the server
4. Edit config.yml if needed
5. Assign row permissions to your ranks
