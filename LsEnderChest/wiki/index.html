LsEnderChest

LsEnderChest is a modern Ender Chest replacement for Paper 1.21.x servers. It replaces the vanilla fixed-size Ender Chest with a permission-based expandable storage system, allowing servers to give players different storage sizes depending on rank, perks, or progression.

Overview Features Commands Permissions Storage Config Guide Compatibility Installation

Overview

Vanilla Minecraft limits Ender Chests to a fixed size. LsEnderChest replaces that behavior with a custom system that lets you decide how many rows a player should have based on permissions.

This makes it ideal for survival servers, donor ranks, store perks, and progression systems. A player can have anywhere from 1 to 6 rows.

LsEnderChest is designed to stay lightweight and simple while still supporting SQLite and MySQL database storage.

Features

  • Expandable storage – players can have 1 to 6 rows.
  • Rank upgrades – permissions can control chest size.
  • Staff tools – admins can open other players' chests.
  • Offline player support – view inventories even when players are offline.
  • SQLite and MySQL support – flexible storage backend.
  • Lightweight design – optimized to avoid unnecessary server load.

Storage System

LsEnderChest stores Ender Chest inventories in a database rather than relying on vanilla storage.

SQLite

Default option and recommended for single servers.

MySQL

Recommended for larger servers or networks.

Config Guide

storage-type: SQLITE

mysql:
  host: localhost
  port: 3306
  database: lsenderchest
  username: root
  password: password

default-rows: 1
max-rows: 6
admin-bypass: true

This configuration file controls how the plugin handles storage and permissions.

  • storage-type – Choose SQLITE or MYSQL.
  • default-rows – Rows given if the player has no permissions.
  • max-rows – Maximum rows allowed.
  • admin-bypass – Allows admins to bypass restrictions.
