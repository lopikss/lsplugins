LsEnderChest

LsEnderChest is a modern replacement for the vanilla Ender Chest system. Instead of using the default fixed storage size, this plugin introduces a permission-based expandable Ender Chest system allowing servers to create rank-based storage upgrades for players.

Expandable Ender Chest System

LsEnderChest replaces the default Ender Chest inventory with a dynamically generated inventory size based on player permissions.

Instead of the vanilla 27 slots, players may have up to 6 rows (54 slots).

enderchest.rows.1 enderchest.rows.2 enderchest.rows.3 enderchest.rows.4 enderchest.rows.5 enderchest.rows.6

The plugin automatically checks permissions using the internal PermissionManager and selects the highest available row permission.

Commands

LsEnderChest provides a simple command system.

/lsec Opens your own Ender Chest. /lsec <player> Opens another player's Ender Chest. (Admin permission required)

Permissions

enderchest.use Allows opening your own chest enderchest.admin Allows opening other players chests enderchest.bypass Bypass restrictions enderchest.rows.1 enderchest.rows.2 enderchest.rows.3 enderchest.rows.4 enderchest.rows.5 enderchest.rows.6 Controls maximum chest rows

Offline Player Support

The plugin supports viewing and editing Ender Chests of offline players.

This is made possible by storing inventory contents inside the database instead of relying on the vanilla Ender Chest storage system.

Storage System

LsEnderChest uses a flexible storage system defined by the StorageProvider interface.

Two storage implementations are included:

SQLiteStorage MySQLStorage

Both storage providers save player inventory contents using serialized ItemStack data.

This allows the plugin to restore Ender Chest inventories exactly as they were stored.

Database Support

Server owners may choose between SQLite and MySQL depending on their setup.

SQLite Default storage No external database required MySQL Recommended for large servers Supports multi-server environments

The database stores:

player_uuid inventory_contents last_update

Plugin Architecture

The plugin is designed with a modular architecture using several manager classes.

LsEnderChestPlugin Main plugin class ChestManager Handles opening and saving inventories PermissionManager Determines row limits based on permissions PlayerIdManager Handles player UUID lookups StorageProvider Abstract storage system MySQLStorage / SQLiteStorage Database implementations

Chest Listener

The plugin listens for Ender Chest interactions using the ChestListener.

When a player interacts with an Ender Chest block, the plugin cancels the default vanilla behavior and replaces it with the custom expandable chest.

This ensures all Ender Chest access is controlled by the plugin.

Update Checker

LsEnderChest includes an integrated update checking system.

The plugin periodically checks if a new version is available and notifies server administrators using the UpdateNotifyListener.

This ensures servers always run the latest version.
