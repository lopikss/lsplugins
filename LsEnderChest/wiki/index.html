LsEnderChest

A modern and lightweight Ender Chest plugin for Paper 1.21.x servers. LsEnderChest replaces the vanilla Ender Chest with a permission-based expandable storage system, letting you give players 1–6 rows depending on rank, perks, or progression.

It is built to stay simple, fast, and configurable while supporting SQLite, MySQL, offline player access, read-only staff viewing, advanced item restrictions, and a dual logging system.

Overview

Vanilla Minecraft limits Ender Chests to a fixed size. LsEnderChest replaces that behavior with a custom storage system that lets you decide how many rows a player should have based on permissions.

This makes it ideal for survival servers, donor ranks, store perks, progression systems, and moderation tools. Players can have anywhere from 1 to 6 rows, while staff can inspect or view other players’ storage when needed.

LsEnderChest is designed to stay lightweight and easy to manage while still covering the features most servers actually need.

Features

Expandable Ender Chests

Players can have between 1 and 6 rows depending on their permissions.

Staff Access

Use /lsec <player> to view or edit another player’s chest depending on permissions.

Advanced Item Restrictions

Restrict items by material, lore, and NBT with blacklist or whitelist support.

Restriction Bypass Permission

Give trusted players or staff a permission to bypass blocked item restrictions.

Async Saving

Chest data saves asynchronously to reduce lag when inventories are closed.

Dual Logging System

Includes a clean simple log and a detailed audit log for staff investigations.

Offline Player Support

Staff can open the Ender Chests of players even when they are offline.

SQLite & MySQL

Choose local database storage or an external database setup depending on your server.

Commands

LsEnderChest keeps commands simple and easy to remember.

Command Description
/lsec Opens your own Ender Chest.
/lsec <player> Opens another player’s Ender Chest. Access depends on permissions.
/lsec reload Reloads the plugin configuration.

Permissions

Permissions control access, row size, and restriction bypass behavior.

Permission Description Default
enderchest.use Allows players to open their own Ender Chest. true
enderchest.admin Allows opening and editing other players’ Ender Chests. op
enderchest.view.other Allows viewing other players’ Ender Chests in read-only mode. op
enderchest.bypass Allows players to use the vanilla Ender Chest block instead of the plugin system. op
enderchest.blocked.bypass Bypasses item restriction checks. op
enderchest.rows.1 Allows 1 row of storage. false
enderchest.rows.2 Allows 2 rows of storage. false
enderchest.rows.3 Allows 3 rows of storage. false
enderchest.rows.4 Allows 4 rows of storage. false
enderchest.rows.5 Allows 5 rows of storage. false
enderchest.rows.6 Allows 6 rows of storage. false

Storage

LsEnderChest stores chest contents outside of the vanilla Ender Chest system. This makes expandable sizes, offline access, and staff tools possible in a clean and reliable way.

SQLite

Best for most single-server setups. Easy to use and requires no extra database software.

MySQL

Best for larger setups or networks that prefer dedicated external database infrastructure.

Supports non-vanilla inventory sizes Better offline player handling Separate from vanilla Ender Chest data

Config Guide

Below is an updated config-guide.yml reference that matches the newer config structure. 

# =========================================================
# LsEnderChest - config-guide.yml
# =========================================================

storage:
  type: "sqlite"

  sqlite:
    file: "EnderChest/database.db"

  mysql:
    host: "localhost"
    port: 3306
    database: "lsenderchest"
    username: "user"
    password: "password"
    parameters: "?useSSL=false&autoReconnect=true"

settings:
  online-mode: true
  default-rows: 1
  tab-complete-offline-players: true

logging:
  simple: true
  detailed: true

title:
  own: "Your Ender Chest"
  other: "%player%'s Ender Chest"

messages:
  no-permission: "&cYou do not have permission."
  player-not-found: "&cThat player could not be found."
  opened-other: "&aOpened %player%'s ender chest."
  reloaded: "&aConfiguration reloaded."
  blocked-item: "&cThat item is not allowed in your Ender Chest."

Important Notes

  • Changing online-mode after players already have data can make inventories appear missing.
  • SQLite is recommended for most single-server setups.
  • MySQL is better for dedicated database environments.

What You Usually Edit

  • storage.type
  • sqlite.file or mysql settings
  • default-rows
  • logging
  • title and messages

Use Cases

  • Give default players a small Ender Chest and higher ranks more space.
  • Offer extra rows as a store perk.
  • Allow staff to inspect chests during support tickets or moderation cases.
  • Review offline player storage when handling suspicious activity or recovery requests.

Installation

1. Download the plugin jar
2. Place it in your server's plugins folder
3. Start or restart the server
4. Edit config.yml if needed
5. Assign row permissions to your ranks
6. Test /lsec in-game
